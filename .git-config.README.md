# Git Configuration for AEE Pipeline

## Configuration File: `.git-config.json`

This file contains git-specific settings for the pipeline scripts.

### Configuration Structure

```json
{
  "repository": {
    "url": "https://github.com/hosamsandid/my_test_repo.git",
    "agent_branch": "agent_workspace",
    "main_branch": "main"
  },
  "user": {
    "name": "Your Name",
    "email": "your.email@example.com"
  },
  "defaults": {
    "auto_sync": true,
    "auto_publish": true
  }
}
```

### Fields

#### repository
- **url**: The git repository URL (SSH or HTTPS)
- **agent_branch**: The branch name used by agents (default: "agent_workspace")
- **main_branch**: The main branch name (default: "main")

#### user
- **name**: Git user name for commits
- **email**: Git user email for commits

#### defaults
- **auto_sync**: Automatically sync with remote (fetch/pull) - default: true
- **auto_publish**: Automatically publish results (commit/push) - default: true

### Usage

The `aee-entry.sh` script automatically reads from this configuration file. Command-line arguments override these defaults:

```bash
# Uses config defaults
scripts/aee-entry.sh

# Overrides auto_sync and auto_publish from config
scripts/aee-entry.sh --no-sync --no-publish
```

### Priority Order

1. Command-line arguments (highest priority)
2. `.git-config.json` settings
3. Script defaults (lowest priority)
